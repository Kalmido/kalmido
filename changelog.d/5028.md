Package 2.1317 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Fixed
- #6331: Office: finalising a document and setting its number check the version of the draft shown (`expect_updated_at`; the web app always sends it). Changed elsewhere in the meantime (another device, a colleague) answers 409 with the current state: nothing is finalised or numbered and the editor shows the bar "Changed in the meantime" with "Reload". Without a version (agents, older clients) the stored state is finalised as before. `POST /api/office/docs/<id>/number` also returns the new `updated_at`.

### Security
- #6496: Support access on hosted servers changes only a fixed list: an account's lock and storage quota, an agent's on / off switch, an organisation's name and symbol. Kid flag and parents, admin right, display name, an agent's owner, webhook, scopes and lists, an organisation's e-mail domains, members and roles are refused (403), so the operator can no longer plant access that outlives the grant. On a hosted server an instance admin listed as a parent of a customer's kid makes its sign-in link only through an open grant and never sets its PIN. The organisation dialog sends no empty member lists.
