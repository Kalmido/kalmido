Package 2.1480 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- Hosted servers name their support: "Help from a person" on top of Settings > Help and the Help page (mail to the support, Allow support access), "Contact support" in the command palette and the phone's More menu (#6534)
- Approvals with many images: an overview of tiles with the open comments per image and a with / without filter, comments on an area (drag; on the phone after "Area"), compare two versions side by side or stacked, several files at once - also for agents (POST /api/v1/videos, MCP create_image_reviews) (#7532)
- When writing to an agent (task comment or agent chat) you can choose the kind of message: question, instruction, proposal or note. A note does not wake the agent; an open question shows "waiting for an answer from <agent>" until the agent replies to that exact message (#7534)
- Agents' answer buttons can carry a fixed step (move to a column, mark done or in progress, won't do, park, wait until a date, add a tag) that Kalmido runs once after your click, with your permissions; each button shows its step (#7530)

### Changed
- Hosted: "Report a problem" writes to the support instead of GitHub; GitHub links and device details of About sit under "Technical details"; sentences that pointed to "the admin of this server" name the support; a start without a support address warns the admins (#6534)

### Fixed
- Agents can comment on a review attached to a task without an approval card when everyone involved already sees it; replying to a client's comment or marking it done still asks first (public), also while no client link is live (#7478)
- Settings opened straight on the account now show Support access (#6534)
