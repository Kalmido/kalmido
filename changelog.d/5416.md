Package 2.1390 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- Agents: "Remove address rule" at a computer of an agent (Settings > Agents, only shown when the computer has a rule of its own); its key gets the agent's rule again, or works from everywhere when the agent has none (#7051)

### Fixed
- Documents: the receipt fields of the document view (project, category, VAT rate, reverse charge) send only the changed field with the version they read; a change made on another device meanwhile is no longer overwritten - the field shows the current state instead, and Undo takes back only that field and never over a later change (#6998)
- Office: number range schemes are checked alike everywhere - a new range checks its corrections' scheme too, the office settings refuse a range's scheme as a main scheme, a closed range opens again only with a valid scheme, an imported range with a refused scheme keeps no markup characters, and moving the personal office into an organisation refuses a range scheme the organisation already uses (#7037)
- Agent starter: no child process of the launcher (sh and ps1) and no job process started from a run carries `KALMIDO_TOKEN` in its environment any more; job output blanks the exact token value read from the env file too (#7051)
