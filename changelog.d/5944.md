Package 2.1482 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- #7385: a new client, calendar or address book created without naming its workspace no longer falls back to "the only organisation you may add to". Nothing named and exactly ONE workspace where the module is on and writable (or the workspace on top) = that one, else `400` `code: space_needed` with the choice - also for a member of one organisation with the module on in Private and in the organisation. The browser always names its workspace; API and MCP callers send `space` / `org_id` (docs/API.md, docs/AGENTS.md, OpenAPI).

### Fixed
- #7385: API v1 now answers a missing workspace with `{"error": {"code": "space_needed", "message", "spaces"}}` (it said only "error" before, without the choice).
