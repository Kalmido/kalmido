### Changed
- Workspace menu: "Add an organisation" shows there only while the person is in no organisation; its lasting place is Settings > Organisation > Workspaces (same dialog), and the settings search finds it, also by "company" (#6885).
- All workspaces: every module shows only the workspaces it is switched on in (Settings > Modules), like the office already did - knowledge, files, reading, tables, workload / absence / dispo, clients, contacts, calendar and the time report; one shared core function `mod_spaces` / `mod_entryOn` in areas.js. When exactly one workspace remains, it opens directly in its colour. Nothing is deleted; search and trash still find everything (#6722).

### Fixed
- Project move: time billed on a finalised document keeps its invoice reference (remembered in `time_entries.billed_moved_doc_id` / `_item_id`) and gets it back when the project returns; time on drafts of the office left behind becomes billable again (#6883).
- Support session: one check in the core (`acx_sup_write` in need_list / need_task / obj_need / need_node) refuses writes into an organisation without its own support grant with 403 `support_session`; the path table `SGA_PATH_ORG` is gone. Final deletes of budget receipts, notepads and office documents are refused in a support session; filed mails hide the secret filing addresses and the original .eml (also in the ZIP download) (#6320, also fixes #7046).
- Security hardening from audit #4741 (#6297): an organisation invitation ends with its admin's right, no invitation row beside a membership, admins counted under an org row lock (1); a value that only looks sealed (`kenc1:`) is sealed like any other (2); restoring a comment / team chat message checks the write rules and who deleted it (`tchat_msgs.deleted_by`) (3); a mail reply through a token needs the token holder's right to comment (4); another person's own ticket types only as their visible project offers them (5); sharing a table by address no longer tells whether an account exists (6); a member deletes from a table / knowledge trash finally only her own (7); agent links to tables, files and knowledge pages need the area's scopes (8); a web run's free texts reach other people only through an approval card (10); the file of a video sign-off version needs `attachments:read` (11); the service worker keeps `/?split=1` under its own key (13); an office upload into an organisation needs the office right on receipts (14); the innerHTML guard sees concatenations and `tr()` with bare values (15).
