Package 2.1508 (Bündel: Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Sicherheit 'Zuletzt bearbeitet': Wissen, Dateien u, Sammelpaket: Aufgaben ohn).

### Changed
- Under "All workspaces" every area whose content is separated per workspace shows the same overview: one short line on top saying what the choice means, "Recently edited" first, then Private and each organisation. The office gets "Recently edited" (#office/recent); Tables gets the overview instead of the mixed list with the "PRIVATE" heading, opens a workspace at #sheets/s/<space> with the path "All workspaces / Name" and its own "Recently edited" page; the sidebar entry of a workspace in Tables opens it (#7564)
- Moving between servers: an export of a newer Kalmido version than the server's is refused everywhere and names both versions (an own server: update to that version first; the hosted server: it takes the file once it runs that version). The export's format number went to 2 once (servers from before refuse such a file with "Update this server first"); the import reads 1 and 2. The double-import guard follows the old server's fixed key (new: `instance_key`, made once at the start, in the manifest's `source.instance`) instead of its address and holds per target organisation (any of its admins), asked exactly in the JSON column (#6593)
- Update across many versions: docs/UPGRADING.md says in short how far back (directly from 2.1000, from 2.37 with one stop at 2.1001.0, before 2.37 through 2.37.0) and "from 2.763 on, back only through a backup" instead of one paragraph per one-way step; Administration > Server and the admin message point to the upgrade guide when more than one minor lies between (#6616)

- One way: no database step without a way back in this package; an account or organisation export written from now on (format 2) is refused by a server older than 2.1508 ("Update this server first") - update the target server first (#6593, #6616)

### Fixed
- Recently edited: Knowledge, Files and Reading ask the same one gate as the lists under "All workspaces" (module card, the organisation's area switch, your own switches, "Also private"), so a member whose module card leaves out a module no longer sees titles of it there; Tables moved onto the same gate (#7706)
- Moving between servers: rows the import leaves out (a required field without a valid value, an amount with more than two decimal places, a row the database refuses) are counted per area and reason and named in the result instead of disappearing silently (#6593)
- A SQLite install from before 2.37 next to an empty Postgres database: the start names the way through 2.37.0 and 2.1001.0 with the command instead of "point DATABASE_URL"; a missing DATABASE_URL next to such a file adds the way (#6616)
