Package 2.1503 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- Retest after the build: the starter's dispatcher can put a built task into review instead of closing it (project switch off / person / read-only review job); the review job ends with works (with evidence) or does not work (with a reason, built again); optional ready command, one review job per project, the same commit is retested once, docs/NACHTEST.md template without values; a task can be sent to a person instead of the review job (people only) (#7535)

### Changed
- Cash book: a quick entry stands at once under the form, the form stays for the next one; no reload after each booking (#7500)
- Bookkeeping receipts: saving shows the row's state ("Saving…", "Not saved – Try again"), the list keeps its loaded rows, taken-over values go into the open sheet (#7502)
- Quotation parts and the shoot calculation sheet save behind the change in one row with the document; no jump back, typed text stays (#7496)

### Fixed
- "My tasks" as a favourite stays: the own person page draws its tile, a stored key the server no longer knows no longer refuses every new favourite, quick changes no longer overtake each other, a refused save says why (#7525)
- Quotation editor: no false conflict after a reload, "Try again" after leaving the editor sends again, a free position added while the catalogue loads is no longer lost (#7496)
