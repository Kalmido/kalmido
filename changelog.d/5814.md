Package 2.1455 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- #7249: Office: with the invoice list filtered to invoice issuers, "Finalise and send all checked" finalises and sends the issuer's drafts without a mark one after the other through the usual finalise and send (no automation); drafts with a new or unconfirmed client, reverse charge, an issuer flag, a payment statement, no sending wished, something missing, an earlier year, an e-invoice warning or no address stay for one-by-one work and show why; the result names each draft (sent / finalised but not sent / skipped).
- #7305: Tables: the cell details beside the grid can be widened by dragging the edge between grid and details (shared grip; double-click = 17.5rem).
- #7308: Timeline and roadmap: the name column can be widened by dragging its right edge; the days, today line and arrows follow (shared grip, own width for timeline and roadmap).
- #7310: Preview windows for PDF, Word / Excel and text files can be widened by their corner grip (centred, at least today's width, at most the window; one width per kind).

### Changed
- #7307: The sidebar folded into the drawer (narrow window or a task open) now has the width dragged for the fixed sidebar and the same grip on its right edge; dragging it there changes both (at most 80 % of the window). Phones unchanged.

### Fixed
- #7305: A grip no longer snaps back to its stored width in the middle of a drag when the view redraws meanwhile (e.g. a table whose frame gets new filler columns while its details are dragged wider).
