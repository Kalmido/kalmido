Package 2.1474 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- Agents: long-polls, the hosted MCP and the assistant share one budget of web threads that always leaves 8 threads for people in the browser (kalmido/core/longslots.py, KALMIDO_AGENT_WAITERS; when full the assistant and MCP answer 503 "The server is busy", a waiting agent gets busy as before; usage in /api/admin/health threads.long); the month's agent usage comes from one counter row (agent_usage_month) instead of a SUM on every API call, GET /api/agents/usage sums per day in SQL, partial indexes for unread agent chat and waiting agent jobs (#6408)
- Dialogs: a dialog that creates something says "Create" / "Anlegen" on its main button (new client, contact, event, birthday, channel, folder, project, table, page …), "Save" only when editing, "Add" only when something existing joins; large dialogs (more than half the window high) always have the close cross at the top right, question dialogs never; question dialogs name their verb instead of a red "OK"; "New client" has the same button height as every dialog on the computer; rule in docs/dev/glossar.md and the check dialog-verb (#6373)
- Saving: every write answer carries the server version (X-Kalmido-V); the app orders its own writes and the loaded state by it instead of a client counter, a two-minute window and up to three reloads - an older state is fetched again exactly once (#7150, step 1; module data in #7522)

### Fixed
- Notes: a new note no longer asks "Changed in the meantime by you - keep your version?" after the first typing; the note takes the server's version when its creation is answered, also for the changes still waiting, and no conflict dialog appears against this tab's own write (#7484)
- Upload token: the switch "Also send to agents" and its hint work for people signed in through a proxy (SSO) instead of answering 403 (#6870)
