Package 2.1463 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Büro: Aussteller-Schlüssel - V).

### Added
- Timeline and roadmap: the name column on the left gets wider by dragging its right edge (or with the arrow keys on the focused grip; a double click goes back to the default); the width is kept per device, separately for the timeline and the roadmap. Phones keep their narrow column (#7308)
- Preview windows of a text file, a PDF and a Word / Excel file: the corner grip makes the window wider (centred, both sides move; at least today's width, at most the window); each kind keeps its width per device. Phones and the picture view unchanged (#7310)

### Changed
- Security: creating an API token, giving a token more rights (a scope, more projects, other addresses), an app password, a personal or team agent, a new agent token, an agent setup code and connecting an app through the hosted MCP access ask for the password again when the sign-in is older than 10 minutes (accounts without a password: sign in again) (#6499)
- Security: switching on the first second factor (authenticator app or passkey) also ends your own API tokens and app passwords, not only the other sessions; the dialog says so (#6499)
- A new personal API token ends after 90 days by default (the dialog preselected it already; the API now too when `expires_days` is left out); "never" stays selectable (#6499)
- Security: wrong second factors (code, passkey, recovery code) count per account over 24 hours; from the 3rd wrong try from an unknown address and at 20 the owner gets a security mail "Someone knows your password"; at 20 the second step works only from an address the account signed in from before or after a reset link that came by mail (#6498)

### Fixed
- A reset or a new password ends the open second-step and enrolment tickets begun with the old password (#6498)
- A private server agent with a left-over membership in a project of an organisation that has the Kalmido AI off reads nothing of that project (#7218)
- A grip keeps the width of a running drag when its view redraws meanwhile (#7308)
