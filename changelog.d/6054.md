Package 2.1498 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Security
- Shared computer: without "Stay signed in" the browser keeps no offline copy of the account; an offline start shows nothing whose last full online sync is older than 14 days; an ended session (401) leaves only the changes not sent yet and forgets the remembered keys and the push subscription; pushes go only to devices whose session still lives; "Stay signed in" is stored with the session (new column sessions.remember, migration 6500, existing sessions filled once by core/oncesteps.d/6500.py: longer than 36 hours and no support session), a support session never keeps an offline copy (#6500)

### Added
- The card Ready to merge carries optional details (SQL, a log) shown folded in a fixed-width font, scrolling sideways on a phone; MCP request_merge_approval passes them on (#7561)

### Changed
- One register of what the browser keeps of an account (icons.js DEV_STORES) and one table which event ends what (devEnd); CI lint tools/check_devstore.py keeps new browser stores in the register (#6500)
- Focus sessions over API v1 are read-only until an admin switches on "Start and stop focus sessions through the API" (instance switch focus_api_write, default off) (#6843, decision #2067)
- A merge request summary over 2000 characters is refused with 400 instead of cut silently (#7561)

### Fixed
- Decided UI back: the event window has Hide on Today again (#3740); Money points not used yet start under Hidden in the menu editor (#3560); the office menu entry is called Address book again (#2647) (#6841)
- Reset under a number scheme puts the pack's default scheme in, not the last saved one (#6843, decision #2264)
- Leaving an organisation leaves what was brought in with it: projects go to an admin, tables, files, knowledge pages and the rest stay; only private projects stay the person's (#6840, decision #935)
