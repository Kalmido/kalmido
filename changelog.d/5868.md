Package 2.1467 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- Development (#7445): a new one-shot data step of the start is a fragment `kalmido/core/oncesteps.d/<task>.py` (function + STEPS entry with phase), run behind the fixed steps of its phase; `tools/check_migrations.py` checks fragments (unique keys, known phase, own `migr_` flags, retired keys), so parallel packages no longer collide on the same lines.

### Fixed
- Bell (#6337): the bell shows the same number on every device: new and read direct messages count at once, "Mark all as read" only reads what was shown (`/api/news/read` takes `max_id`), "seen for today" and dismissed items reach the other devices, the day change refreshes the counts, and the quiet-hours summary push never names more than still waits.
- Offline start (#6340): an offline start shows how old its state really is ("State from Tuesday, 14:05" in the header chip title, the tap message and the waiting-changes bar) instead of the time since the page opened; the start state is written when the page is hidden, so changes made just before closing are in the next offline start.
- Offline queue (#6334): with several tabs or the background sync a task created offline no longer shows twice in the creating tab, the queue order is a rising counter instead of the device clock, provisional ids are replaced in every field (milestone, parent, previous values), the service worker leaves notes and knowledge pages to the app and keeps the offline start state current, and the id map is trimmed by send time.
- New version (#6338): the app does not reload by itself while an upload runs and closing the tab asks; an outdated window reloads before it would load a part of the new version; a refused multi-file upload in Files removes the files it had already written.
