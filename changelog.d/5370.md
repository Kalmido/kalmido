Package 2.1383 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Meine Aufgaben: Knopf „Neue Aufgabe“ überdeckt bei, Starter-Parität: Dispatcher-Reste).

### Added
- Reference starter dispatcher (#7041): optional `brief_required` - only tasks with a bold decision, a Where section and a size are built, others become `needs_brief` (#4062); places come from the work style's `max_parallel`, capped by `places`; a 409 `slots_full` holds only the next build job (#5199); a reminder ten minutes before a job's time limit, never a follow-up job (#4063); every override of a safeguard is logged at start and counted (#4064); the day report names median hours from built to closed, the share of jobs ending with open tasks and the overrides (#4061).

### Changed
- Start page: under "All workspaces" the rows of the Projects and Notes cards carry their workspace's dot and name, via the org colour building block `wso_origin` (#6234).

### Fixed
- Long lists with many sections (e.g. Built) scroll smoothly again: the windowed list no longer searches every section's spacers and measures every section on each frame (#6935).
- Bell: the "For you" and "History" heads stand flush, full width and opaque at the top while scrolling; no row shows above or beside them (#7023).
- My tasks on phones: the list ends with room for the floating + button, so it never covers "New section" (#7060).
