Package 2.1176 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- Files and documents: loading, errors and empty states use the shared blocks - a folder, the document list, the file search, a saved view and the History / Sharing tabs show a clear sentence with "Try again" instead of raw server text, a second toast or "No results"; a missing folder shows the no-access block; the title is the folder's name or "Files", never "Organisation" (#6109).
- Document upload names the server's reasons in one message instead of "Error 400"; the 400 answer carries them as `error` too (#6109).
- Contacts speak like the glossary: "Move to the trash" in every menu, "view only" instead of "read only", "Merges" heading, "Person/Company"; deleting one or several contacts no longer asks and offers Undo, also via Ctrl+Z and Recent steps; deleting an address book has Undo too (#6124).
- Lists: every failed write says what was not saved; the invitations and the folder share dialog show a load error with "Try again" instead of "not shared"; loading spots use the shared spinner; the board shows its empty state when grouped and a "Filter active" hint when a saved view or sprint hides everything; removing an invitation offers Undo (#6139).
- Lists: people who may only view get a task menu with Copy link, Print and History; a single task can be printed; sharing a folder by address, roles and removing people are shown only to its owner (#6136).
