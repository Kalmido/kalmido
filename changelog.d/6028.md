Package 2.1495 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- My tasks: the "+" on the head of an own section (Now, Soon, Someday and your own ones; not "Recently assigned") adds a task right there - an input under the head on a computer, the quick sheet on a touch screen; the task is assigned to you, lands in the project the quick add of My tasks uses (a typed ~project wins, else the Inbox) and stands on top of that section; one Undo takes it away. One "+" for every group through the section adapter (newAt / placed), no second input (#7512)
- Task panel: in a project with a repository or environments a stage line on top - Created › In progress › Built › Version › each environment (Staging, Live …) › Done (or Rejected); reached stages ticked, the current one stressed with "Parked: reason" / "Waiting for …", "2× back" after reopening and with whom the task lies; a tap lists every stage with its date. Read from the column meaning, the repository's build state, the environments (milestone or same version) and the history; nothing is stored. A phone shows only the current stage written out (#7537)
- Starter dispatcher: `approved_cmd` (`KALMIDO_DISPATCH_APPROVED_CMD`, default empty) runs once after the person's yes on the card "Ready to merge", so the integrator sees the yes at the git server (e.g. a label); no shell, placeholders {url} {number} {branch} {base} {title}; rejected or open: nothing; a failure is told once, never retried; it never merges (#7562)

### Changed
- Office lists work on what they show instead of the data of all years: the cash book year (cancellation links once, full columns only of the shown entries), the cash box overview (sum in SQL), the credit card sheet (suggestions only from documents of the same amount, the keys read once), the cash flow (only trips with a receipt in the period, only the bank matches of the shown receipts) and a trip's answer (only its billed documents). Measured on test data: cash book year 333 -> 52 ms, card sheet 713 -> 43 ms, cash flow 99 -> 13 ms; same answers (#7506)
