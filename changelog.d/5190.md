### Action needed
- #6668: Team agents with their own starter or program: from the first request token on, the agent's own long-lived token reaches only its channel (events, status, chats, jobs, cards); project content needs a request token (`POST /api/v1/agent/request-token`). Update the starter (agent_launcher.sh / .ps1) - it asks for a request token before every run and starts nothing without one. A program that never asks keeps working as before.

### Added
- #6698: Additional number ranges per office area (Settings > Office > Number ranges): own counter, own date order and own hash chain, corrections with their own suffix (e.g. `-K`) in the same counter, dunning per range (off by default). The main scheme and counter stay as they are. In a range Kalmido sets the document date when finalising; hand numbers are refused. A range with a finalised document can only be closed, not removed. Ranges move with a private office transfer and go through the organisation export/import and the retention/auditor export. New table `office_num_ranges`, column `office_docs.range_id` (migration 6698).
- #6668: An external team agent (own token, own starter, hosted MCP) works per request for exactly one person: the request token has the same cut as a server run (that person's projects, writes capped to their role); events without a person allow reading their projects only and every change becomes an approval card. Removing a computer ends all request tokens of the agent; hosted MCP of a team agent works for the person who connected it. Starters (.sh, .ps1), MCP, agent docs and the in-app setup guide follow (migration 6668: column `agents.per_request`). An approved card runs a read-only step (e.g. a work package export) with the long-lived token only inside the agent's own channel; everything else needs the request token.
- #6960: "Tomorrow" shows a foldable group "Still open from today" on top (due today or overdue, same rule as "Today"); the tasks of tomorrow follow below. The sidebar count of Tomorrow is unchanged.

### Fixed
- #6962: In "My tasks" with own sections, "Move to section…" in the context menu and in multi-edit offers the own sections (with "New section…"); the project's sections are behind their own entry "Move to section of <project>…".

### Changed
- #6948: Test suite for the number scheme change at the turn of 2026 -> 2027 (GS-{yyyy}-{seq:03}, corrections in the same counter with -K, a parallel GT range): chain, counters, December drafts, DATEV, income statement and e-invoice stay correct.
