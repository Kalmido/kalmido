Package 2.1460 (Bündel: Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- #6372: Error messages say what did not work in plain words instead of the server's raw text (about 170 places in 85 files, also the office imports: a too large file no longer says "Payload Too Large"); views with their own error block (calendar, contacts, contacts trash) show no second message. A failed CSV export of documents now says the export could not be made. New CI guard tools/check_errtext.py keeps raw `toast(e.message)` out.
- #6377: Accessibility: input fields without a name get one for screen readers (comment edit, new password, passkey password / code, project search, status note, description and more); the fold arrows of list sections ("Overdue", "Today", own sections, Done, Trash) and "Events today" in the calendar are buttons with open / closed state, usable with the keyboard; green text and the work / off status colours are darker in the light theme (contrast 4.5:1); the mention link shows a focus ring; the quick add sheet is a named dialog; the page behind a dialog is inert.

### Fixed
- #6365: Cold start and reload show the chosen theme, accent and font size from the first picture (small boot script static/js/boottheme.js at the top of the page) - no short flash of the system colour, no logo flash on a reload within the session.
- #6381: No wrong state before content: "Loading…" appears only after 300 ms and the old view stays until the new one can draw (office, contacts, files, family, statistics, feeds, bookmarks); the Agents page no longer shows "No running or waiting jobs" before the answer; a not yet loaded project on a large account shows loading instead of "No tasks"; Done, Trash, News and Time switch at once on the click and load their list afterwards.
- #6154: Calendar: opening an event read-only no longer creates a calendar silently; a person's own calendar in an organisation where they only view has no "Leave" and no own-name label.
