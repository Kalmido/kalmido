Package 2.1208 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- Start page tells loading, empty and failed apart: each card shows a placeholder of fixed height while it loads, one sentence when empty and an error with Retry when it failed; nothing stands twice (News leaves out what "Waiting for you" already shows); an empty account gets a "First steps" card instead of grey "...: nothing" lines; the bell, its window and the start page all say "Waiting for you"; "All news" / "All projects" sit as a link in the card head (#6125)
- One "Switch to" menu for the head bar, the phone's workspace button, the drawer's brand and the workspace badges: organisations, Private, All, then "Add an organisation" and the organisation's settings; "organisation" instead of "company", "sidebar" instead of "panel" (#6127)
- Phone "More" holds only what the tab bar does not show (overflowing tabs, Search, Settings, Customise tab bar) - no areas of the drawer, no News beside the bell (#6127)
- Favourites show their name (shortened with an ellipsis) on the phone and in a wide head bar, not only a symbol (#6127)
- Date dialog of a task: Repeat sits right under Today / Tomorrow / Next week; reminders (chips, fixed time, repeat reminder) are a block of their own, shut unless a reminder is set; "Repeat reminder" has the bell, no longer the repeat symbol (#6138)

### Fixed
- Undo / Redo of an upload's new version sends the version it knows (expect_version): when someone else uploaded a newer one meanwhile, the file stays as it is and the message says so; other refusals (locked month, folder switching) are said as they are (#6173)
- Uploads into the file store and the documents say a refused part once, in the list of what stayed out, not a second time as a pop-up message (#6173)
- Each upload has its own list of what stayed out; a second upload no longer removes the first one's list (#6173)
