Package 2.1363 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Fixed
- #6720 Organisation colour in the calendar: an event opened through its address (`#ev/<id>`, from a push or News) shows its organisation's stripe and name like a tapped one, and under "All workspaces" the event popover wears the organisation's tone as its accent (Edit in its colour). Due tasks of an organisation's project in the month and week grid carry the same stripe as the events next to them.
- #6728 Agent dispatcher: the mark that a task is the person's own text (`by_creator`, `tasks.origin`) is cleared for good once another account (or a webhook, public link, CalDAV, list rule or git sync) changes its title or description. A task copied from a server, a chat message saved as a task and the `Rest:` task of a release carry no mark. Only a signed-in session, the proxy sign-in and the person's own token count as written by hand. The hint under Agent > Work the list off says so.
- #6862 Support access: on a client's agent the operator can only pause and resume it. Delete, reset, avatar, test event and removing a device answer 403 like the other closed ways; reading (devices, usage, audit) stays.
