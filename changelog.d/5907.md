Package 2.1475 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- #7494: Every client request has a shared time limit (read 15 s, write 20 s, long work such as upload, import, bank fetch, PDF and export 5 min). A read without an answer is retried once silently, then the page shows its error block with "Try again"; a write without an answer says "Not saved: no answer from the server" with "Try again", which resends the same request with the same Idempotency-Key, so it lands exactly once. Every write now carries an Idempotency-Key; the import previews ("Reading…") no longer hang. The remaining raw fetch() calls follow in #7521.
- #6871: With KALMIDO_TEST=1 the app writes a loud warning line to the log at every start, and instance admins see a lasting red box "Test mode: test routes are open" under Settings > Server.

### Changed
- #6872: The old last four characters of server agent API keys and newsletter tokens are emptied once at the update; the hint under the agent's key field no longer mentions them.

### Fixed
- #7509: Quotation and invoice editor: quick changes in a row (quantity, price, header fields) are no longer lost or jump back while an earlier save is still on its way, and a service chosen from the picker always lands in the current document. A failed document load waits for "Try again" instead of reloading on every redraw.
- #7507: Office on a slow connection: Save in the office dialogs (master data, fixed costs, cash-flow correction, contracts, templates, new letter, travel "settle receipts", meal approval, new client, quotation / project from the pipeline, lead conversion) locks the button while it works and sends one key per dialog, so a double press creates nothing twice. Load errors show "Try again" instead of "does not exist", "Nothing matches." or an empty place (letter, recipient search, timesheet card, number ranges, recurring vendors; key figures keep the shown numbers with an error line). Receipt sheet, cash book entry and the walk-through show a loading bar and open once. Logbook, cash-flow check, letter blocks, meal invoice upload, office agents and "File in folder" report errors visibly. The archive import shows "Archiving {0} of {1}…"; project times and the invoice-from-time preview draw only the latest answer; cash flow, import, cash book and logbook load their parts at the same time.
