Package 2.1466 (Bündel: Release-Tor (judge_soft): übersprungener Nacht-Job, Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- Call sheets: the project tab uses the shared loading, error (with "Try again"), empty (with "New call sheet") and no-access blocks; "New call sheet" and the logo choice are proper dialogs (Enter confirms, errors stay in the dialog); sending by mail moves focus to the heading after every step, the Send button keeps its icon after a failure, and without mail set up a dialog offers "Download PDF"; the mail group is called "Drehpersonal" in German (#6149)
- Release gate (tools/ci_gate.py): a job that ci.yml runs only at night or by hand (if: schedule || workflow_dispatch, read from the tagged tree) no longer counts as "hard job did not run" when it was skipped; Lint, the shards and every other hard job stay hard (#7412)

### Fixed
- A write whose answer got lost after the server did the work (a dead spot, a proxy 502) is no longer done twice: every write carries its idempotency key from the first try and keeps it in the offline queue (Duplicate task makes one copy); an upload of the same files to the same task sent again keeps its key; the team and agent chat keep a message's client_id over a failed try and the server recognises it at any time, also with files; a comment with only files and a changed selection is a new comment (#6332)
- My tasks: your own rules with a project tag keep working when the tag gets a new id (a project joins an organisation with a label of that name, the tag move of 2.947); a rule whose tag is gone says "Tag missing" in the rules dialog instead of doing nothing (#6289)
- Team chat: the earlier versions of the messages of a project's channel follow the project into another organisation or into private; deleting a message for good removes its versions also when they belong to an organisation the person is not in; the history kind is known from the start of the server (#6232)
