Package 2.1456 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Changed
- The window "Recent steps" (right-click / long-press on the back arrow) can be resized like the bell: a grip in its lower left corner (keyboard, double-click = default size), at least 20 x 16rem, at most the rest of the browser window; the size is kept per device and the list fills the dragged height. The page #steps and the phone stay as they were (#7311).

### Fixed
- Mail sender names: a display name, the office's sender name for mails or an older stored name with an @, < > or a web address (e.g. "service@paypal.com") is refused on input and never put in front of the server's address in an outgoing mail (#6549).
- Agents: the MCP fence now also marks a contact's name, company and note and an event's place written by another account as data; an event booked on the public booking page carries `origin: "booking page"` and `untrusted: true` in the API (#7414).
- Offices: an admin demoted through the server admin's whole set of admins starts in the company's start group (e.g. Staff) with a rights log entry instead of the silent "Previous access"; a start group can only be Staff, Read-only or None (#7413).
- Quotation approval page: "included in the PDF (from page N)" only when the terms pages really were joined; otherwise the sentence names the terms' state with a link to download them. The page never fails on a render error (#7416).
- Backups: `bkstore.py decrypt` leaves no half plain zip behind when the disk is full (exit 1, the next try works) (#7416).
