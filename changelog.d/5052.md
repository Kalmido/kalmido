Package 2.1325 (Bündel: Weich rot: p290_ui, Weich rot: perf_ui, Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- #6668 External team agents (own token, own launcher, MCP remote) now work for exactly one person per request: `POST /api/v1/agent/request-token {"seqs": [...]}` gives a short-lived token cut to the asker of those events with the same cut as the server run (`srv_run_cut`): only the asker's projects, the asker's role as ceiling, changes a reader could not make become cards; `{"operator": true}` cuts to the person chosen in the agent settings; without an asker the token reaches only the projects of the events and every change becomes a card. Once an agent fetched a request token (`agents.per_request`), its own token reaches only its channel (`403 request_token_needed` otherwise). MCP remote cuts a team agent's token to the person who connected it. Reference launcher (`agent_run.py`, `agent_dispatch.py`, `.sh` and `.ps1`, capability `request_token`), docs/AGENTS.md, AGENT-SETUP, CLAUDE.template and the in-app rules follow (new module `agents/reqtoken.py`, migration `6668`).
- #6502 New notification kind "Support access" (bell and push, can be switched off in the notification settings): co-admins learn of an organisation's support grant and its early end, the client (or all org admins) of the first use; the person granting access gets a security mail.

### Changed
- #6502 A support session reads only the person's private space, own office and organisations whose admins granted support access themselves (`core/access.py` `_ctx_support`, built per request, never cached per account); reads through an org grant are logged in that grant's log. Changes made in a support session carry `via='support'` in the history and show "(support access)"; the grant log keeps write entries up to 3000 (the 300 cap is for reads only), counts what drops out and shows it, and a log entry hit by a lock or error is retried in the background instead of lost. A support sign-in no longer counts as a known device or address of the client (migration `6502`).

### Fixed
- #6665 Test p290_ui checks the app password form of 2.1271.0 (8-symbol id + 4 x 5 secret).
- #6666 Test perf_ui measures the app start after one plain text page (a fresh runner's first-draw cost stays out of `start_ms`) and logs where the start time goes.
