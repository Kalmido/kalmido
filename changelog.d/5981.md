Package 2.1488 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Security
- Shared computer: without "Stay signed in" the browser keeps no offline copy of the account; an offline start shows nothing whose last online sync is older than 14 days; an ended session (401) leaves only the changes not sent yet and forgets the remembered keys and the push subscription; pushes go only to devices whose session still lives (#6500)

### Added
- The card "Ready to merge" shows an agent's details (SQL, a log) folded in a fixed-width font, scrolling sideways on a phone; request_merge_approval and the starter dispatcher pass `details` on (#7561)

### Changed
- What the browser keeps of an account has one register with classes and one table "event x class" (static/js/icons.js devEnd); sign-out, account switch, restore, ended session and sign-in mark all go through it; a session ends on the server in one place with its push subscriptions (ses_end); CI lint tools/check_devstore.py (#6500)
- A merge request summary over 2000 characters is refused with a clear message instead of being cut silently (#7561)
- Leaving an organisation leaves everything of its area with it again, also what the person brought in from their private space; only private projects stay theirs (#935, #6840)
- The event window offers "Hide on Today" again (#3740); unused Money points of the office start under Hidden until used (#3560); the office menu says Address book again (#2647) (#6841)
- Reset under a number scheme puts the default scheme back, not the last saved one (#2264); focus sessions over API v1 are read-only until an admin allows starting and stopping them (Settings > Server, #2067) (#6843)
