Package 2.1294 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher), Agenten-Dispatcher der App (mcp/agent_dispatch.py)).

### Changed
- Kalmido AI on a hosted server: an agent on the Kalmido server always keeps a hard daily limit in tokens. The first key sets the default (2,000,000 tokens) if none is given; the limit can be changed, never removed, and stays below the operator's ceiling per agent (Administration > Agents, "Daily limit per agent at most", default 10,000,000). Agents from before get the default before their next run. Runs nobody asked for (public form, mail inbox, incoming webhook, listening in, server reminders) may use a quarter of the daily limit; then they stop with a clear reason while requests of people keep running. Self-hosted servers are unchanged (#6568).
- Kalmido AI: the server agent passes every block of the model's answer back unchanged (also its thinking), so runs with several steps no longer fail at the provider; an answer may have up to 16,000 tokens (one call up to 5 minutes, a run up to 15). A refused or cut-off answer ends the run with its own message instead of passing on half a text (#6573).
- Agent dispatcher of the app (mcp/agent_dispatch.py): builds only tasks the person wrote themself in the app or with their own token (new task origin, API field `by_creator`) - never tasks of other members, tasks without a creator, or tasks from an inbound webhook, a mail to the list or the inbox, a form, an import or a sync, even when they carry the person as creator; tasks from before this version count as not written by the person; skipped tasks are named in the log, the dry run and the daily report ("not yours"). Comments of other accounts reach the job only inside a data fence, never as an order (#6523).
- Docs: the knowledge area notes its known limit - who has Can edit on the whole area can guess the name of a folder kept out for them, never its pages (#6325).

### Fixed
- Security, support access: through a client's support access the operator now changes only what is listed - on an account lock / unlock and the storage quota, on an agent pause / resume, on an organisation its name and icon. Making the client's account a kid with the operator as parent, taking over or redirecting a client's agent, and changing an organisation's e-mail domains or members are refused (403). On a hosted server an instance admin is no parent of a client's kid, so sign-in links, PIN and rewards need the support access and end with it (#6496).
