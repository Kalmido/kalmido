Package 2.1459.0 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).

### Added
- Sign-in (#6354): a new passkey, switching on app codes, a new API token, app password or agent token now send a security mail (an agent's token mail goes to its owner). Changing the password with the box "end all app passwords and API tokens" now also ends the task feed, calendar and absence feed links and the upload token (also on admin reset and reset link); the dialog says that passkeys and your own agents stay and points to them.
- Office (#6937): people without an organisation can start the move of their own personal office in Office > Settings beside its export (confirm with your user name); while it moves the bar "Your office is moving" shows and office data is read-only, the private area stays writable.

### Changed
- Files (#6405): the file store finds what each person may see through indexed queries and reads the rights of a whole folder, the crumbs and the trash at once; folders with more than 500 entries show "Load more" at the bottom (`/api/files?parent=…&limit=N` answers `more`; without `limit` all children as before).

### Fixed
- Privacy (#6356): deleting an account or an organisation for good now also removes bookmark pictures, agent chat files, the account import upload and quotes of the person in agent rules, independent of the retention switch.
- Restore (#6357): restoring an older backup keeps pending account deletions (and withdrawn ones stay withdrawn), deletes again every kind with a trash plus absences and external bookings that were deleted for good since, and never sets invoice number counters back; the restore dialog names the extra kinds.
